


###### create conda PyAPS environment (python3)

conda create -n PyAPS python=3.6 numba h5py scipy astropy
conda activate PyAPS

conda install -c conda-forge fitsio
conda install -c conda-forge astropy-healpix

## install desiutil, desispec, redrock
git clone https://github.com/desihub/desiutil
cd desiutil ;  python setup.py develop install ; cd ..
git clone https://github.com/desihub/desispec
cd desispec ;  python setup.py develop install ; cd ..
git clone https://github.com/desihub/redrock
cd redrock ; git clone https://github.com/desihub/redrock-templates py/redrock/templates ; cd ..
cd redrock ; git clone https://github.com/desihub/redrock-archetypes py/redrock/templates ; cd ..

cd redrock ;  python setup.py develop install ; cd ..

# at this point you're ready to install PyAPS

## REDROCK installation :

1- Get the latest version of the REDROCK CODE FROM:
https://github.com/desihub/redrock
Unzip and rename it to 'redrock'

2- install basic python packages
pip3 install fitsio (--user)
pip3 install numba (--user)
pip3 install h5py (--user)


3- go to the desiutil directory contains the setup.py file
python3 setup.py develop (--user)

4- go to the desispec directory contains the setup.py file
python3 setup.py develop (--user)



5- Get the latest version of the templates for redrock from:
https://github.com/desihub/redrock-templates

6- Get the latest version of the archetypes for redrock from:
https://github.com/desihub/redrock-archetypes



7- go to the redrock directory contains the setup.py file
python3 setup.py develop (--user)


## RVSPECFIT installation:


1- Get the latest version of the RVSPECFIT CODE FROM:
https://github.com/segasai/rvspecfit
Unzip and rename it to 'rvspecfit'


2- install python packages

pip3 install numpy (--user)
pip3 install matplotlib (--user)
pip3 install astropy (--user)
pip3 install pyyaml (--user)
pip3 install scipy (--user)
pip3 install numdifftools (--user)
pip3 install pandas (--user)




3- go to the rvspecfit directory contains the setup.py file
python3 setup.py develop (--user)

*** if no root permission, you should add --user to be able to copy bin files in the 
bin path of your system (e.g. on a shared machine)

4- make sure the related executable files are in the bin directory.
e.g. /Library/Frameworks/Python.framework/Versions/3.7/bin/
IMPORTANT: Make sure you have the "rvs_read_grid" in your bin path.
		   It's neccessary to generate templates in the next step
** and probably you should delete junks (rvs_weave, ...)




5-  Get the latest version of the templates from:
ftp://phoenix.astro.physik.uni-goettingen.de/v2.0/HiResFITS/PHOENIX-ACES-AGSS-COND-2011/Z-0.0.Alpha=+0.80/
and you may need the "WAVE_PHOENIX-ACES-AGSS-COND-2011.fits" file, that could be found in the:
ftp://phoenix.astro.physik.uni-goettingen.de/v2.0/HiResFITS/


6- Run the script make_rvs_templates_MOS.sh, located in the grid_generator subdirectory of PyAPS. You may need to modify it first
   to point to the right raw templates path.



## FERRE installation:
1- Get the latest version of the FERRE CODE FROM:
https://github.com/callendeprieto/ferre
Unzip and rename it to FERRE or FERRE4.8.8 or whatwever you want

2- go to the src directory and do
make clean
make 
make install

NEW UPDATE (16 July 2020):
To solve the problem with inconsistency between course and fine grids for WDs, we replace are m file for grids 6-9 with the n ones
rm m_rweave[6789]* ; find . -type f -name 'n_rweave[6789]*' | while read FILE ; do     newfile="$(echo ${FILE} | sed -e 's/n_rweave/m_rweave/')" ; cp "${FILE}" "${newfile}" ; done

Later, we will solve this issue by adding a patch to the code.

Moreover, keep all 0 grids (new WDs) in a separate directory called new_WDs


Converting all ascii grids to binary form:
Cd to the directory contains the .dat grids (for ferre)
ls -1 *.dat | awk '{print "echo "$0" | /scratch/aps/PyAPS_modules/FERRE4.8.8/bin/ascii2bin "}' | sh



3- make sure ferre.x and ascii2bin have been already copied into the bin directory inside this package
